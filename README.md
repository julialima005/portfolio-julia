# Portfólio de Júlia Lima

Criei este portfólio como projeto final de uma disciplina da graduação em Engenharia de Software na UDF. Nele, conto um pouco sobre mim e reúno quatro projetos que desenvolvi durante o curso.

[Abrir meu portfólio](https://julialima005.github.io/portfolio-julia/)

## Meus projetos

| Projeto | O que desenvolvi |
| --- | --- |
| Amazônia: Brasil Verde | Site em HTML e CSS com uma galeria de fotos de animais da Amazônia. |
| Dia das Crianças | Site em Bootstrap com cartões, carrossel de imagens e janela de informações. |
| Cursos e Funcionários | Banco de dados em MySQL com consultas para identificar os funcionários inscritos em cada curso. |
| Calculadora em C | Programa de terminal que usa `switch` para escolher entre soma, subtração, multiplicação e divisão. |

## Como construí o portfólio

Usei HTML para organizar as seções, CSS para personalizar as cores e a tipografia e Bootstrap para montar os cartões e o menu de navegação. No computador, os projetos aparecem em duas colunas. No celular, ficam em uma coluna, e o JavaScript do Bootstrap permite abrir e fechar o menu.

## Organização dos arquivos

- `index.html` — página principal do portfólio.
- `css/style.css` — estilos personalizados.
- `js/bootstrap.bundle.min.js` — JavaScript do Bootstrap.
- `imagens/` — fotos e capturas de tela dos projetos.
